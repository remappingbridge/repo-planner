# UIC task policy

Every UIC gate must produce: exact source references, normative draft changes in `remappingbridge/mouse`, compatibility analysis, tests/fixtures where applicable, unresolved decisions, and acceptance evidence.

Contract rules are semantic first. Do not copy private structs from either repository merely to finish a gate quickly.

Human architecture review is mandatory at UIC-00, UIC-03, UIC-05 and UIC-08.
